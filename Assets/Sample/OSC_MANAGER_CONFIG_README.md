# OSC Manager 設定UI

## 概要
`OSCXPositionYVectorManager`の主要な設定をUIで操作できるコントローラーです。
ToggleとInputFieldを使って、リアルタイムでパラメータを変更できます。

## 特徴
- ✅ **リアルタイム設定変更**: UIから即座にマネージャーの設定を変更
- ✅ **わかりやすいToggle**: 前後無視/区別、後進のみ、左右連続検出をワンクリック切替
- ✅ **数値入力**: クールダウン時間、角度閾値、ベクトル閾値を細かく調整
- ✅ **自動検証**: 入力値を適切な範囲にクランプ
- ✅ **デフォルトリセット**: 設定を初期値に戻す機能

## セットアップ手順

### 1. UIの準備
Canvas内に新しいGameObjectを作成し、`OSCManagerConfigUI`という名前にする

### 2. コンポーネントのアタッチ
`OSCManagerConfigUI`コンポーネントをアタッチ

### 3. UI要素の作成

#### Toggle要素（3つ）:
1. **前後無視モード Toggle**
   - ON: 前進も後進も同じ値を送信
   - OFF: 前進と後進で異なる値を送信

2. **後進のみモード Toggle**
   - ON: 後進連続検出を有効化
   - OFF: 無効

3. **左右連続検出 Toggle**
   - ON: 左右連続検出を有効化
   - OFF: 無効

#### InputField要素（3つ）:
1. **クールダウン時間 InputField**
   - 送信間隔（秒）
   - 範囲: 0.01〜10秒

2. **Y軸角度閾値 InputField**
   - Y軸ベクトル方向の角度閾値（度）
   - 範囲: 0〜90度

3. **Y軸ベクトル最小閾値 InputField**
   - Y軸ベクトルの最小強さ
   - 範囲: 0.001〜1.0

### 4. コンポーネントの設定

#### Target Manager
- **Target Manager**: `OSCXPositionYVectorManager`をアサイン

#### Toggle UI Elements
- **Ignore Forward Backward Toggle**: 前後無視モードのToggleをアサイン
- **Enable Backward Mode Toggle**: 後進のみモードのToggleをアサイン
- **Enable Side Detection Toggle**: 左右連続検出のToggleをアサイン

#### InputField UI Elements
- **Cooldown Time Input**: クールダウン時間のInputFieldをアサイン
- **Y Angle Threshold Input**: Y軸角度閾値のInputFieldをアサイン
- **Y Vector Threshold Input**: Y軸ベクトル最小閾値のInputFieldをアサイン

#### Settings
- **Enable Debug Log**: デバッグログを出力するか（デフォルト: false）

## 各パラメータの説明

### 1. 前後無視モード（Ignore Forward/Backward）
**Toggle**: ON/OFF

- **ON（デフォルト）**: 前進も後進も、左右の値のみを送信
  - 前進で左 → `leftValue`
  - 後進で左 → `leftValue`（同じ）
  - 後進のみモードは無効化される

- **OFF**: 前進と後進で異なる値を送信
  - 前進で左 → `leftValue`
  - 後進で左 → `leftBackwardValue`
  - 後進のみモードと併用可能

### 2. 後進のみモード（Enable Backward Mode）
**Toggle**: ON/OFF

**前提条件**: 前後無視モードが OFF の時のみ有効

- **ON**: 後進が連続すると、後進値のみを送信するモードに切り替わる
  - `consecutiveBackwardLimit`回後進すると有効化
  - `forwardRequiredCount`回前進すると解除

- **OFF**: 後進連続検出を行わない

### 3. 左右連続検出（Enable Side Detection）
**Toggle**: ON/OFF

- **ON**: 同じ方向（左または右）が連続すると、その方向にロックされる
  - `consecutiveSideLimit`回連続すると方向固定
  - `oppositeSideRequiredCount`回反対方向で解除

- **OFF**: 左右連続検出を行わない

### 4. クールダウン時間（Cooldown Time）
**InputField**: 数値入力（秒）

- **範囲**: 0.01〜10秒
- **デフォルト**: 0.3秒
- **説明**: OSC送信の最小間隔。この時間が経過するまで次の送信は行われない
- **例**:
  - 0.1秒 → 1秒間に最大10回送信
  - 0.5秒 → 1秒間に最大2回送信

### 5. Y軸角度閾値（Y Angle Threshold）
**InputField**: 数値入力（度）

- **範囲**: 0〜90度
- **デフォルト**: 45度
- **説明**: Y軸ベクトル方向の判定角度。Y軸からこの角度以内なら前後として判定
- **例**:
  - 45度 → 比較的緩い判定
  - 30度 → より厳密な判定

### 6. Y軸ベクトル最小閾値（Y Vector Threshold）
**InputField**: 数値入力

- **範囲**: 0.001〜1.0
- **デフォルト**: 0.1
- **説明**: Y軸ベクトルの最小強さ。この値以上でないと方向として認識されない
- **例**:
  - 0.05 → 小さな動きでも反応
  - 0.2 → 大きな動きのみ反応

## 使い方

### 基本的な使い方
1. セットアップが完了したら、Playモードに入る
2. ToggleをON/OFFして、挙動の変化を確認
3. InputFieldに値を入力して、動作の微調整を行う
4. リアルタイムで設定が反映される

### プログラムから制御する場合

```csharp
public OSCManagerConfigUI configUI;

// 設定をデフォルトに戻す
configUI.ResetToDefaults();

// UIを再読み込み
configUI.RefreshUI();
```

## トラブルシューティング

### 設定が反映されない
- `Target Manager`が正しくアサインされているか確認
- ToggleやInputFieldが正しくアサインされているか確認
- コンソールにエラーが出ていないか確認

### 後進のみモードToggleがグレーアウトしている
- これは正常な動作です
- 前後無視モードがONの時、後進のみモードは使用できません
- 前後無視モードをOFFにすると、後進のみモードが有効になります

### 入力した値が変わってしまう
- 入力値が範囲外の場合、自動的に範囲内にクランプされます
- 各パラメータの範囲を確認してください

## 技術詳細

### 値の検証
InputFieldで入力された値は、以下のように検証されます：
- **クールダウン時間**: 0.01〜10秒にクランプ
- **角度閾値**: 0〜90度にクランプ
- **ベクトル閾値**: 0.001〜1.0にクランプ

無効な値（数値でない文字列など）が入力された場合、元の値に戻されます。

### 連動機能
前後無視モードToggleをONにすると、後進のみモードToggleが自動的に無効化されます。
これは、前後を無視している場合、後進のみモードが意味をなさないためです。
